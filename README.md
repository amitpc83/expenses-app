# Expenses App

Full-stack expense tracking application with a .NET API backend and Angular frontend.
Users can add income and expenses, view transactions, and track their balance.

## Structure

```
expenses-app/
├── backend/Expenses.Api
└── clients/web/expenses-app
```

## Run

### Backend

```
cd backend/Expenses.Api
dotnet run
```

### Frontend

```
cd clients/web/expenses-app
npm install
ng serve
```

## Notes

Make sure the frontend is configured to call the backend API (e.g. https://localhost:5001/api).



## Notes

Make sure the frontend is configured to call the backend API (e.g. https://localhost:5001/api).
